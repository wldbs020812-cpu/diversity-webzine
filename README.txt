2026 부산 문화다양성 주간 아카이빙 웹진

GitHub 업로드 방법
1. 이 ZIP 파일을 먼저 압축 해제합니다.
2. webzine-final 폴더 안의 index.html, pages, videos, images, fonts를 모두 선택합니다.
3. GitHub 저장소의 Add file > Upload files에 끌어놓고 Commit changes를 누릅니다.
4. index.html이 저장소 최상단에 있어야 합니다.

구동 방식
- 화면 오른쪽: 다음 페이지 / 화면 왼쪽: 이전 페이지
- 키보드 방향키와 모바일 좌우 스와이프 지원
- 오른쪽 위 메뉴 버튼: 목차 열기
- 8페이지와 22페이지: 원본 사진 다음에 영상 전용 화면이 이어짐
- 영상 전용 화면의 썸네일 클릭 시 확대 재생
- 확대 영상 바깥 오른쪽 클릭: 다음 페이지
- 확대 영상 바깥 왼쪽 클릭: 이전 페이지
- ESC: 영상 또는 목차 닫기
